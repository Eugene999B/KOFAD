# KOFAD cookie choices

Essential sign-in, CSRF, basket and required workflow storage remain available.
Optional theme/sound storage is used only with preference consent. Visitors can
accept available optional cookies, keep essential only, or save individual
choices. Reopen Cookie choices at the bottom of any main website or staff page.
Choices are host-only, SameSite=Lax, Secure on HTTPS and expire after 180 days.
No consent cookie contains an account ID, telephone number or email address.

No analytics is configured by this change. To connect a company-owned free
Google Analytics 4 property, set KOFAD_GA4_MEASUREMENT_ID on the web service.
The browser loads Google's analytics script only after opt-in and only on
approved public pages. Staff/private account and order pages never render the
measurement ID. Search query strings, referrers and private URLs are excluded
from page events; Google Signals and advertising personalization stay disabled.
Third-party analytics still receives network information when the visitor opts
in. Do not add other trackers outside this consent mechanism.

Rejecting analytics disables future events and clears known Google Analytics
cookies. A previously downloaded script cannot be undownloaded, and withdrawing
consent does not erase records already received by the provider. No marketing
trackers are introduced. Revisit the privacy notice before adding new vendors.
