RECOVERY RULES

What KOFAD protects

Server enforced

Backup files are never trusted by filename. KOFAD checks their signature, checksum, record manifest and migration schema on the server. Restore and reset require the signed-in system administrator’s current password, an exact typed phrase, an explicit acknowledgement and a fresh safety backup.
