3 · RESTORE

Replace the current system from a backup

Restore replaces the current Core and Marketplace database state with the selected backup snapshot, including customer accounts, online orders, product media, support history and operational records. Active browser sessions are invalidated. You will be signed out after a successful restore.

RECOVERY RULES

What KOFAD protects

Server enforced

Backup files are never trusted by filename. New downloads are encrypted before leaving the server and KOFAD checks authenticated encryption, signature, checksum, record manifest and migration schema during recovery. Legacy signed plaintext backups remain restorable for compatibility. Restore and reset require the signed-in system administrator’s current password, an exact typed phrase, an explicit acknowledgement and a fresh safety backup.
